Este projeto é uma página simples de login criada usando **HTML** e **CSS**.

##  Sobre o projeto
O objetivo deste projeto foi praticar conceitos básicos de desenvolvimento web, como:
- Estruturação de páginas com HTML
- Estilização com CSS
- Criação de formulários
- Centralização de elementos na tela

Objetivo de aprendizado:
Este projeto foi desenvolvido como prática inicial de desenvolvimento front-end para aprender melhor HTML e CSS.

 Projeto feito para fins de estudo.
